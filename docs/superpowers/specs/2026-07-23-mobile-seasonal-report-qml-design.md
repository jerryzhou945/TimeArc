# TimeArc 手机端季节月报与真实数据叙事设计规格

## 1. 目标

把已确认的网页原型 `monthly-report-web-v7.html` 迁移为可运行的 Qt 6/QML 手机端功能，并接入 Android 实际使用数据。交付范围包括：

- 四季美术语言下的 12 个月份独立背景与排版；
- 六页式全屏月报；
- 由真实数据驱动的多维文案引擎；
- 月报、单应用卡牌和周期排行榜的一键分享；
- 动效、减少动态、无数据和权限不足状态；
- Android 月度历史数据补齐。

本规格扩展并取代 `2026-07-19-mobile-qml-time-album-design.md` 中“记忆湖与月报”和“分享”的月报部分。首页、统计、记忆湖、我的既有信息架构保持不变。

## 2. 已确认的体验

### 2.1 月报结构

月报为六页全屏故事，用户点击左右区域或横向滑动翻页：

1. 月份封面；
2. 总时长、记录天数和连续天数；
3. 本月最有辨识度的时间事实；
4. 常见应用组合；
5. 应用时长排行与月度变化；
6. 可直接分享的月报结尾。

顶部保留分段进度和关闭按钮，不自动翻页。页面切换采用短距离横移、淡入和轻微景深变化。

### 2.2 视觉原则

- 背景是细腻的二维动画电影式场景，有自然光影、空间纵深和真实季节氛围。
- 不在背景图里绘制文字、卡牌、Logo、人物或 UI；所有信息由 QML 渲染。
- 页面文字不放进大面积装饰卡片。仅证据说明和分享海报使用必要的半透明可读层。
- 白色正文通过页面暗角、局部 veil 和文字阴影保持可读，不破坏背景氛围。
- 不固定使用 TimeArc 信号色。按钮、进度条和强调色随月份主题变化。
- 生产版本不加载网络图片；背景和图标均来自本地资源或 Android 实际应用图标。

## 3. 十二个月份系统

最终提供 12 张本地月份背景。现有四张原创图片作为春、夏、秋、冬美术基准，另外八张沿同一笔触、材质和构图质量扩展，不使用简单调色冒充独立背景。

| 月份 | 场景 | 主要动态 | 优先叙事 |
|---|---|---|---|
| 一月 | 冰霜湖畔或霜窗 | 细霜、慢雪 | 深夜、年度开场 |
| 二月 | 融雪庭院 | 檐下水滴、暖光 | 首次出现、记录恢复 |
| 三月 | 雨后花园温室 | 竖直春雨、薄雾 | 连续天数、雨夜长会话 |
| 四月 | 花影长廊 | 花瓣、移动光影 | 下午时段、应用组合 |
| 五月 | 向阳书房或长日庭院 | 浮尘、长光束 | 连续天数、白昼使用 |
| 六月 | 雷雨河岸 | 急雨、远处闪电 | 最长一次、晚间峰值 |
| 七月 | 萤火河岸 | 萤火、夜雾 | 深夜记录、夜间组合 |
| 八月 | 晚夏雨巷 | 稀疏重雨、积水微光 | 平均会话、节奏放缓 |
| 九月 | 金色风谷 | 风叶、远景雾层 | 新应用首次出现 |
| 十月 | 落叶回廊 | 银杏落叶、长影 | 年内最长连续记录 |
| 十一月 | 初霜清晨 | 霜粒、呼吸雾 | 清晨迁移、月度回落 |
| 十二月 | 雪夜书室 | 落雪、灯光呼吸 | 年度累计、归档 |

月份之间不只更换背景。`MonthProfile` 同时决定：

- 六页的标题、布局变体和信息顺序；
- 背景资源、暗角强度、文字区域和强调色；
- 粒子类型、数量、速度和景深；
- 文案语气与候选洞察优先级；
- 分享海报标题和月份落款。

## 4. QML 组件边界

### 4.1 `MobileMonthlyStory`

负责全屏容器、当前页、手势、进度、关闭和减少动态。它不计算业务指标，也不拼接文案。

### 4.2 `MobileSeasonScene`

输入 `MonthProfile`，只负责：

- 加载当前月份本地背景；
- 渲染暗角、光照和季节粒子；
- 在页面切换时进行轻微视差；
- 在减少动态模式下关闭循环动画，仅保留静态场景。

雨滴必须使用独立粒子，具有不同长度、速度和延迟，不能使用会产生横向接缝的重复纹理。

### 4.3 六个故事页面

使用共享排版原语，但允许月份配置改变构图：

- `MonthlyCoverPage`
- `MonthlyOverviewPage`
- `MonthlyHighlightPage`
- `MonthlyCompanionPage`
- `MonthlyRankingPage`
- `MonthlySharePage`

页面从统一 `MonthlyReportModel` 读取内容。无可用洞察时，页面可替换为诚实的记录覆盖说明，不显示空白数字。

### 4.4 分享组件

月报、单应用卡牌和周期排行榜共享 `MobileShareStoryModel`，但由三个专用版式消费：

- `MonthlyReportPoster`
- `AppTimePoster`
- `PeriodRankingPoster`

屏幕预览、保存图片和 Android 系统分享使用同一个 QML 组件，通过 `grabToImage` 导出，避免预览与实际分享不一致。

## 5. 数据模型与服务边界

### 5.1 `MobileUsageInsightEngine`

新增纯数据叙事组件，输入仓库返回的每日汇总、会话、当前周期和对比周期，输出候选洞察。它不依赖 QML，不访问网络，不直接读写数据库。

候选洞察包括：

- 主要使用时间段；
- 报告范围内首次出现的应用；
- 最长一次已观测会话；
- 深夜记录次数、时长和最晚结束时间；
- 最长连续记录天数；
- 同日共同出现的应用组合；
- 当前月与上月的绝对变化和百分比变化；
- 有记录天数、覆盖范围和数据完整度。

每条洞察包含 `kind`、结构化数值、证据日期、置信度和可分享标记，不只返回一段不可解析的字符串。

### 5.2 文案选择

引擎为候选洞察计算分数：

- 数据置信度；
- 相对用户自身历史的辨识度；
- 覆盖天数；
- 与月份主题的匹配度；
- 与已选洞察的内容差异。

每份报告选择两到三类互不重复的强洞察。月份配置只改变优先级和语气，不能改变事实。

文案由确定性模板生成，不调用外部 AI。所有“相当于”换算必须明确标注为换算，不能声称用户真的播放了多少首歌、阅读了多少字或观看了多少部影片。

### 5.3 置信度和降级

- “最长一次”优先使用 Android `UsageEvents` 得到的已观测会话。
- 估算会话只能表达为“可确认记录中较长的一段”，不能表达为绝对最长。
- 只有每日汇总时，应用组合只能表述为“同一天共同出现”，不能表述为同时运行。
- 上月为零时不显示无限百分比，改为“本月第一次形成完整记录”。
- 历史不足时显示记录覆盖范围，例如“本月只保存了 8 天记录，这份月报仅讲述可以确认的部分”。
- 无权限时不展示模拟数据，提供授权和同步入口。

## 6. Android 数据补齐

当前 Android 已能读取真实应用汇总、应用名称、图标和近期会话，但现有同步窗口不足以稳定生成整月洞察。迁移时调整为：

- 每日汇总至少补齐当前月和上一个完整月；
- 会话事件尽量回溯 35 天；
- 初次授权或长时间未同步时按自然日分块回填；
- 使用幂等 upsert，重复同步不产生重复记录；
- 后台任务暴露进度、最近成功时间和可用数据范围；
- 设备或系统不提供更早事件时保留能力标记，由文案引擎降级。

不得修改 service-owned SQLite、采样服务或 C ABI。Android 使用数据仍写入 GUI 私有数据库，由现有移动仓库读取。

## 7. 资产与性能

- 12 张背景存放在移动资源目录，以月份命名。
- 源图保留在设计资产目录；运行时版本使用约 9:16、足以覆盖高密度手机的压缩 JPEG。
- 单张运行时背景以约 300–700 KB 为目标，避免 12 张原始 PNG 全部进入安装包。
- 月报只加载当前月份背景；相邻故事页共享同一纹理，不重复解码。
- 页面关闭后释放非当前月份图片和不可见粒子。
- 粒子数量按设备性能和“减少动态”设置降低。
- 分享导出前等待背景和应用图标进入 Ready 状态，失败时使用本地纯色与首字图标回退。

## 8. 月份排版差异

四季提供基础布局节奏，12 个月进一步改变主要信息构图：

- 冬季偏垂直、留白和单列时间线；
- 春季偏轻盈错位、雨滴或花影引导；
- 夏季使用更大的时间数字和更深的夜间层次；
- 秋季使用长路径、排行和连续日期形成阅读方向。

每个月仍遵守同一安全区、最小字号、44×44 点击区域和六页导航规则，避免为了差异破坏可用性。

## 9. 分享

### 9.1 月报

默认导出一张适合社交信息流的 3:4 海报。海报使用当前月份原创背景、月份标题、主洞察、三条事实、前三应用及本地数据说明，不提供四个风格选项。

### 9.2 单应用

从首页卡牌背面直接分享，包含真实应用图标、名称、累计时长、首次记录、记录天数、一条换算文案和一条个性化洞察。背景默认使用用户壁纸；没有壁纸时使用主题纯色。

### 9.3 周、月、年、总排行

统计详情提供单一“一键分享排行”，包含周期范围、总时长、前三至前五应用、相对进度和周期文案。用户壁纸作为背景，并自动叠加可读 veil。

匿名模式隐藏应用名称和图标，不允许包名、设备标识、原始窗口标题或联系人信息进入分享模型。

## 10. 错误、空状态和无障碍

- 背景加载失败：保留月份强调色和粒子，显示纯色季节场景。
- 图标加载失败：使用稳定首字图标，布局不塌陷。
- 数据同步中：显示已覆盖日期和同步进度，不显示最终月报结论。
- 分享导出失败：保留预览并提供保存重试。
- 正文和按钮达到 WCAG 2.2 AA 目标对比度。
- 减少动态时关闭粒子、闪电、视差和大幅横移动画。
- 页面可通过触摸和键盘方向键操作，选中状态不只依靠颜色。

## 11. 验证标准

### 数据

- 固定数据集能稳定生成时间段、首次出现、最长一次、深夜、连续天数、应用组合和月度变化。
- 不完整会话、上月为零、跨月、跨年和无数据均有确定结果。
- 相同输入生成相同文案，候选选择不存在随机性。
- Android 回填重复执行不增加重复记录。

### QML

- 390×844 预览下 12 个月均能打开六页报告。
- 12 张背景、月份强调色、排版变体和动态元素匹配配置。
- 三月雨滴保持竖直独立下落，无横向纹理接缝。
- 快速切换页面、关闭报告和切换月份没有 QML warning。
- 减少动态、浅色/深色、用户壁纸有无均可读。

### 分享

- 月报、单应用和四个统计周期都能生成预览、保存并调用 Android 分享。
- 真实图标 Ready 后不显示首字缩写。
- 匿名模式和普通模式均不泄露包名或敏感上下文。

## 12. 非目标

- 本轮不实现 iOS 数据采集。
- 不增加云端 AI 文案、云同步或在线主题商店。
- 不修改桌面端 UI。
- 不复制网易云音乐、小红书或 B 站的具体视觉资产和版式。
- 不修改 service 采样流程、service SQLite schema 或 C ABI。
