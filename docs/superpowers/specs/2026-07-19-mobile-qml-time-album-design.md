# TimeArc 手机端 QML“口袋时间相册”设计规格

## 1. 目标

将 `docs/prototypes/timearc-mobile-social-v3.html` 中已经确认的设计语言转化为
可运行的 Qt 6/QML 手机端体验，并接入现有 Android UsageStats 数据。交付覆盖
首页、统计、记忆湖、我的四个页面，以及全局壁纸、卡牌翻转、卡牌分享、月报
和移动端权限/同步能力。

本轮不是像素照搬网易云音乐、小红书或 Days Matter，而是保留用户认可的沉浸
壁纸、清晰排行和纪念卡分享结构，继续遵守 TimeArc 的“证据先于故事、隐私先于
洞察”原则。

## 2. 已确认的产品决定

- 采用 QML 完整重构加一个聚焦的 `MobileUiService`，不做仅供观看的静态皮肤。
- 首页每次只展示一张居中卡牌。相邻卡牌在视口外等待，不叠放、不重复透明层。
- 四个底部页面共享同一张用户壁纸；没有壁纸时使用主题纯色。
- 统计首页包含“本周、本月、今年、总计”四个独立入口。
- 进入统计周期后，排行逐行展示真实图标、通俗应用名、时长和明显的相对进度条。
- 卡牌背面可以直接打开统一分享预览；不提供多套风格选择器。
- 月报背景由 QML/Canvas 原创绘制，不打包第三方照片。
- 技术名词、包名、SQLite 和 UsageStats 不出现在主要产品界面。

## 3. 架构

### 3.1 不变的服务侧

后台采集、service-owned SQLite、`data_bridge.h` 和数据库路径契约全部保持不变。
Android 数据继续由现有同步桥写入 GUI 数据库并由
`MobileUsageRepository` 读取。本功能不增加采样源，不修改表结构，也不让 UI
写入 service 数据库。

### 3.2 UI 数据聚合

`MobileUsageService` 继续提供移动使用数据，并扩展为适合界面直接消费的模型：

- 周从周一开始，月从当月 1 日开始，年从 1 月 1 日开始，总计从最早记录开始。
- 每个应用除时长和占比外，提供首次记录日期、实际记录天数、覆盖日历跨度。
- 展示名优先使用 Android 应用标签；为空或明显是包名时再应用常见名称映射。
- 图标优先使用同步得到的 `appIconPath`，失败后使用 `image://appicon/`，最后才
  使用应用首字回退。
- 记忆湖模型只从日期、时长、记录天数、排名和应用组合生成叙事，不虚构打开
  次数、播放次数、阅读字数或情绪结论。

### 3.3 移动 UI 服务

新增 `MobileUiService`，作为一个注册到 QML 的 `QObject`，只负责 UI 私有文件：

- 导入用户选择的本地图片并复制到应用私有目录。
- 保留原始像素，不为适配屏幕预先放大；QML 只在一个全局 `Image` 上使用
  `PreserveAspectCrop`。
- 暴露当前壁纸 URL、导入失败信息和恢复默认操作。
- 为 QML `grabToImage` 提供安全的临时/导出路径。
- 在 Android 上将导出的 PNG 通过受控 `content://` URI 交给系统分享面板。
- 在桌面移动预览中至少保存 PNG 并返回可访问的本地路径。

壁纸和分享图属于 UI 私有文件，不进入 service 数据库或 service 配置。

## 4. 全局界面骨架

`MobileAppShell` 是唯一壁纸拥有者：

1. 底层为主题纯色。
2. 有壁纸时只创建一个全屏 `Image`，填充模式为 `PreserveAspectCrop`。
3. 页面只叠加自己的可读性 veil，不重复创建或缩放壁纸。
4. 四个页面用持久实例或等价缓存承载，切换标签时保留滚动位置、统计周期、
   卡牌索引和翻转状态。
5. 底部导航遵守安全区，四个入口为“首页、统计、记忆湖、我的”。

浅色壁纸模式使用很轻的中性 veil 和深色文字；深色模式使用暗 veil 和浅色文字。
无壁纸时页面回到 `MobileTheme` 的实体色和不透明信息面。

## 5. 首页

### 5.1 档案事实

顶部去除社交资料感，只保留三个事实：

- 开始记录的日期；
- 累计记录时长；
- 有记录的使用天数。

它们位于一条可读的透明信息带中，不出现头像、等级、徽章或页面快捷入口。

### 5.2 单卡轮播

- 横向滑动时当前卡离开，下一张卡移动到中心。
- 视口内只渲染当前卡的完整信息，不显示叠放侧卡。
- 卡牌正面接近透明，让壁纸直接通过；下半部使用渐变保护文字。
- 正面显示真实应用图标、通俗名称、当前周期时长、占比和一句证据化文案。
- 点击卡牌或“查看时间百科”翻到背面，翻转约 220–300ms，无弹跳。
- 无壁纸时正面使用可读的实体/半实体主题面，不出现空洞透明块。

### 5.3 时间百科背面

背面保持低饱和暖棕色，展示：

- 初次记录日期；
- 累计记录时长；
- 实际记录天数；
- 从初次记录到今天的日历跨度；
- 一句带“相当于”或“若换算”的明确换算文案。

换算必须使用透明、固定的规则，例如“若连续播放一首 4 分钟歌曲，相当于约
N 首的时长”，不能表述为用户真的播放了 N 首歌。

## 6. 统计

### 6.1 周期首页

统计页首次进入显示四个功能块：

- 本周：本周一至今天；
- 本月：当月 1 日至今天；
- 今年：当年 1 月 1 日至今天；
- 总计：最早记录至今天。

每个块只预览总时长、记录天数和排名第一的应用，点击进入详情。布局不使用四张
完全相同的“指标卡网格”；通过不同信息密度和一条共享排行预览形成整体。

### 6.2 周期详情

详情页标题明确显示日期范围，并按时长降序排列：

1. 真实应用图标；
2. 通俗软件名称；
3. 格式化时长；
4. 相对于当前周期第一名的水平进度条；
5. 可选的周期占比文字。

进度条长度以第一名为 100%，保证视觉差异清晰；数字仍显示该应用占总时长的
真实百分比。返回操作回到四周期首页，并保留上次选择。

## 7. 记忆湖与月报

记忆湖由三部分组成：

- 本月原创季节封面，使用 QML Shape/Canvas 绘制叶片、雨线、光点或雪层等抽象
  氛围元素，不使用现成照片；
- 一个整合后的月度报告入口，包含记录天数、累计时长、主要应用和一句月度故事；
- “最近被记住”时间流，展示三到五条由真实数据生成的文艺但克制的片段。

示例文案结构：

- “在本月 N 个有记录的日子里，X 一直留在时间线上。”
- “这段 N 小时 M 分钟的使用，被分散在 K 个日子里，没有挤成同一天。”
- “X 与 Y 共同组成了本月最常出现的两种节奏。”

月报打开后是一个五段式全屏故事：封面、总览、主要应用、时间分布、分享结尾。
不自动播放；页面切换只做短时横移/淡入，并支持关闭。

## 8. 我的

“我的”页面承担真实可用的移动设置：

- 使用情况访问权限与当前状态；
- 立即同步和最近同步反馈；
- 自动同步；
- 明暗模式；
- 选择壁纸、显示当前壁纸状态、恢复默认；
- 分享时默认匿名；
- 隐私说明和本地优先说明。

设置项通过 `SettingsRepository` 持久化。权限缺失、壁纸导入失败或同步失败时，
在当前行下方展示可恢复的中文错误状态，不弹出无法行动的模态框。

## 9. 分享

卡牌背面的分享按钮打开一个统一预览面，而不是多个模板选项。海报包含：

- TimeArc 小型来源标识；
- 真实应用图标和通俗名称；
- 一个主数字（记录天数或累计时长）；
- 日期范围；
- 一句故事；
- 两条事实；
- 一条明确限定的换算；
- 隐私提示。

匿名模式隐藏应用名与图标，并移除应用品牌色。预览、保存 PNG、系统分享使用同一
个 QML 海报组件，避免导出内容和屏幕预览不一致。任何窗口标题、联系人、网址、
设备标识和原始包名都不得进入分享模型。

## 10. 状态、错误与无障碍

- 无数据：首页展示授权/同步教学卡；统计入口仍可见但标注“暂无记录”；记忆湖
  展示不伪造数字的空状态。
- 图标失败：回退到由应用名称生成的首字图标，布局不坍塌。
- 壁纸失败：保留旧壁纸并显示错误，不覆盖为损坏文件。
- 分享失败：保留预览并提供“保存图片”重试。
- 所有可点击区域最小 44×44 QML 像素。
- 文字和信息面达到 WCAG 2.2 AA 的目标对比度。
- 不只用颜色表达选中、错误或进度状态。
- 系统启用减少动态效果时，翻转和页面转场缩短为即时切换或淡入。

## 11. 验证标准

### 数据与单元测试

- 周、月、年、总计起始日期符合日历语义。
- 常见包名能得到预期的通俗名称，已有 Android 标签不被覆盖。
- 每应用首次日期、记录天数和跨度来自仓库记录。
- 壁纸导入成功、失败不覆盖旧值、恢复默认均可验证。
- 分享模型在匿名与非匿名状态下不会泄露包名或敏感上下文。

### QML/运行验证

- 390×844 移动预览下四页可导航且无 QML warning。
- 浅色/深色 × 有壁纸/无壁纸四种组合均可读。
- 首页任意时刻只出现一个完整卡牌面，滑动和翻转状态正确。
- 四个统计入口可进入对应详情，真实图标、名称、时长与进度条一致。
- 卡牌分享预览、保存路径和 Android 系统分享路径可用。
- 月报使用原创 QML 图形，没有外部图片依赖。
- 运行后必须扫描 Qt 日志，提交前通过完整 Harness 检查。

## 12. 边界与延期

- 本轮不实现 iOS 分享适配。
- 本轮不修改桌面端页面设计。
- 本轮不增加云同步、社交关系、点赞或公开动态。
- 本轮不修改 service 采样、service SQLite schema 或 C ABI。
- 如果 Android 厂商无法返回应用图标，使用一致的本地回退，不下载网络图标。
