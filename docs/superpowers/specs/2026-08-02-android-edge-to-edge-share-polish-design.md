# Android 全屏、图标与分享体验设计

## 目标

在不恢复会导致鸿蒙卓易通启动退出的自定义 Activity Theme 的前提下，完成 Android/HarmonyOS 移动端的 Edge-to-Edge 全屏、统一圆角图标、华为系统应用友好名称与图标，以及单应用卡片/月报分享预览的视觉重构。

## 已确认的产品决策

- 采用 Edge-to-Edge：背景延伸到状态栏和底部手势区，但保留系统时间、信号、电量和手势条。
- 所有应用图标均通过统一圆角遮罩显示，圆角半径约为边长的 22%，透明图标保留安全边距与底色。
- 设置和分享操作使用同一套 Material Symbols Rounded SVG，不再使用 Unicode 字符充当图标。
- 分享预览覆盖整个应用层级；底部导航不穿透显示。
- 数据库保留原始 package/class 标识，友好名称和图标修复只发生在 Android 元数据解析与 UI 展示层。

## 视觉方向

沿用 TimeArc 的「Pocket Time Album」：低饱和湖青、冷色中性表面、克制的圆角和清晰的大数字层级。分享海报是可保存的时间纪念卡，不是设置页或统计面板截图；避免嵌套玻璃卡、超长空白和技术包名。

## Edge-to-Edge

Android 启动后通过 Java 运行时 Window API 关闭 decor fitting，将状态栏和导航栏设为透明，并根据浅色模式切换系统图标明暗。QML 根背景绘制到窗口四边；标题、关闭按钮、滚动内容和底部导航使用 `SafeArea.margins` 预留交互安全区。Manifest 中 `QtActivity` 继续使用系统默认 Theme，不绑定 `TimeArcLaunchTheme`。

## 图标系统

从 Google Material Symbols 官方仓库选取所需 Rounded SVG，作为离线 qrc 资源打包。设置项采用 20px 线性图标置于 36px 圆角容器；分享动作采用 22px 白色图标置于 42px 圆角容器。新增 Apache-2.0 文本、README 和应用内许可清单。

应用图标由 `MobileAppIcon` 统一裁切：外层固定圆角、内部图片覆盖完整槽位并保留 3px 安全边距。无真实图标时根据系统应用类别使用语义 SVG，否则使用首字 fallback；所有入口、排名和分享海报复用同一组件。

## 华为元数据

Android 解析器先从 UsageStats 标识中提取可查询的基础包名，再调用 PackageManager。`com.huawei.android.launcher` 及其 `LauncherApplication` 变体统一显示“华为桌面”；常见 Activity/Class 后缀不进入可见文本。查询失败时 C++ 展示层仍提供已知包映射和可读 fallback，确保旧数据库记录也立即改善。

## 分享预览

单应用卡片和月报共用全屏预览结构：安全区内的紧凑标题栏、居中的响应式 9:16 海报、状态反馈和固定分享动作栏。

单应用海报只保留真实圆角图标、友好名称、核心时长、日期范围、一句故事、两项事实和一个轻量换算。月报以季节场景为主体，使用底部渐变承载月份标题、总时长、活跃天数和最常出现应用；移除嵌套半透明大卡。长名称最多两行，任何包名或类名都不得出现在导出图中。

## 验收

- 鸿蒙卓易通仍可启动，不恢复 Activity 自定义 Theme。
- 状态栏与底部手势区显示页面背景，系统信息仍可见。
- 设置页不再出现方框缺字；所有功能图标风格一致。
- 所有真实/回退应用图标均为统一圆角。
- 华为桌面显示友好名称和有效图标或 Home fallback。
- 两类分享预览在窄屏内无裁切、无大面积无意义空白、底部导航不穿透。
