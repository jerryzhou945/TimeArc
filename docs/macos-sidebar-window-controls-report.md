# macOS 侧栏窗口控制改造

## 目标

仅在 macOS 移除可见标题栏，把关闭、最小化、全屏交通灯直接放入左侧栏；Windows、Android
和其他平台保持原有窗口框架与布局。

## 范围与改动

- macOS 桌面窗口使用 Qt 完全无边框模式，不创建 AppKit 标题栏或标题区域。
- 左侧栏在 macOS 下贴合窗口左、上、下边缘，并移除圆角、描边与投影边界。
- 新增 macOS Objective-C++ 宿主：AppKit 绘制标准关闭、最小化、全屏按钮；宿主补齐整组
  悬停符号状态，并在全屏时禁用最小化按钮，不创建标题栏。
- `WindowChrome.qml` 在 macOS 仅保留顶部拖动和四周缩放命中区；Windows 仍显示原有右上角控制键。
- 备忘黑板打开时沿用原逻辑隐藏窗口控制层。

## 验证

- 修改前、修改后均通过 `.harness/tools/build.py` 构建。
- macOS 构建产物可启动；Objective-C++ 与 QML 编译通过。
- 静态确认 Windows 分支的边距、侧栏边界、品牌图标和右上角控制键默认值未改变。
- Qt 日志扫描只重复读取到既有 LaunchAgent/旧启动日志；沙箱无权轮转外部日志文件。

## 已知限制与回滚

若需回滚，删除 AppKit 窗口样式适配并恢复 QML 控件即可；不涉及数据库或服务数据恢复。
