# 应用名称与图标稳定性更新报告（2026-08-25）

## 更新结果

- 微信不再使用错误的助手/更新程序图标，也没有加入自定义微信素材；TimeArc 会优先读取本机仍存在的 `Weixin.exe` / `WeChat.exe` 默认图标。
- 统计、会话与应用管理统一使用稳定的代表程序路径。软件升级后，仍存在的新路径优先于已经失效的旧版本路径，降低图标偶发变成字母占位的情况。
- 设置 → 追踪与应用 → 应用管理新增“编辑名称”。原始 ID 始终只读，自定义名称支持中文与常用字符。
- 自定义名称仅改变首页、统计和应用管理中的显示文字，不改变应用 ID、历史分组、计时逻辑或数据库结构；可随时“恢复默认名称”。

- `timearc_db_smoke`：通过（覆盖显示名称不改变分组键、微信主程序优先、有效路径优先）。

- Qt 桌面目标：通过 harness 包装构建。
- CTest：6/6 通过，包含数据库、资源、番茄钟、Windows 前台和音频策略测试。
