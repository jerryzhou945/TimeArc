# 应用 ID 与图标稳定性更新报告（2026-08-25）

## 更新结果

- 微信不再使用错误的助手/更新程序图标，也没有加入自定义微信素材；TimeArc 会优先读取本机仍存在的 `Weixin.exe` / `WeChat.exe` 默认图标。
- 统计、会话与应用管理统一使用稳定的代表程序路径。软件升级后，仍存在的新路径优先于已经失效的旧版本路径，降低图标偶发变成字母占位的情况。
- 设置 → 追踪与应用 → 应用管理新增“编辑 ID”。原始 ID 只读，自定义 ID 统一保存为 `app:<slug>`。
- 自定义 ID 仅存于 TimeArc 的 UI 设置；后台服务原始记录与数据库结构不变。修改后历史记录在读取时重新归组，可随时“恢复默认”。
- 如果目标 ID 已存在，第一次保存只显示合并风险，第二次点击“确认合并”才执行。
