# Windows 发布默认项、游戏计时与应用时钟（2026-08-25）

## 本次结果

- Windows 首次成功启动会为当前用户注册 `TimeArc.exe --start-in-tray` 登录项，
  不需要管理员权限。设置页中的开关仍然是最终决定；用户关闭后会记录选择，
  以后启动不会自动重新开启。
- 原神、崩坏：星穹铁道、绝区零和鸣潮的主游戏进程在前台时持续计时，
  键鼠空闲、手柄操作、剧情和加载不会把有效游戏时间切断。
- 游戏最小化、切到其他应用或退出后立即失去前台证据；启动器和任意通用
  `Client-Win64-Shipping.exe` 不会因为进程存在而被计时。
- 统计页每日应用时钟保留三条并发轨道、应用图标、悬停放大和点击交互，
  轨道半径由 `0.50/0.62/0.74` 收紧为 `0.54/0.63/0.72`，减少视觉散落。

## 数据与平台边界

没有修改数据库结构或 journal 契约。游戏策略只给当前前台采样增加工作证据，
不会把普通后台进程改成活跃时间；macOS、Android 和现有 Discord/媒体/Codex
专用策略均未改动。

## 验证

- 完整包装构建通过。
- CTest 6/6 通过。
- 统计 JS、桌面 UX 静态检查和周期布局静态检查通过。
- 在真实 Windows 用户环境验证 Run 项为
  `"D:\\TimeArc\\time-arc\\build\\TimeArc.exe" --start-in-tray`，
  UI 与独立采集服务同时运行。
