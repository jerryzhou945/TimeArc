# 桌面统计周期布局更新报告

## 目标

减少周、月、年统计中的重复信息和纵向空间浪费，让趋势、分类和全部应用各自只承担一个清晰任务。

## 范围

- 周/月/年改为左右布局：左侧为周期总览与分类分布，右侧为时间趋势；统计内容区仅在小于 900px 时回落单列，常见约 1100px 桌面内容区保持双列。
- 周/月/年的周期总览改为 132px 高横向摘要，移除用于撑高的空白占位；双列区整体高度压缩为 440px。
- 移除周期 Top 应用排行；“所有应用”成为唯一应用明细入口。
- 日视图移除重复的 24H 时间线与 Top 排行，保留应用时钟和今天的组成。
- 应用时钟新增点击锁定：悬停临时突出，点击保持突出，再次点击或点击空白解除。
- 不修改服务采集、数据库契约、聚合口径或移动端统计页。

## 验证

- Track B 预检与修改前完整构建。
- 统计布局静态回归测试覆盖左右拓扑、重复区块删除和时钟点击锁定。
- 完成后通过 harness 构建、CTest、统计专项测试与 Qt 日志扫描；最新桌面运行未产生 Qt/QML 警告。

## 已知边界

- 周/月/年仍沿用现有真实聚合数据与柱状趋势，不新增统计维度。
- 小于 900px 的窄内容区继续切换为单列，以保证内容可读。

## 回滚

如需回滚，整体撤销本次统计周期布局提交；不需要迁移或清理任何用户数据。
