# TimeArc 手机端时间相册 QML 实装报告

日期：2026-07-19
分支：`codex/mobile-qml-full-ui`

## 已完成

- 全局壁纸只渲染一次，首页、统计、记忆湖、我的共享同一张原始图片；使用
  `Image.PreserveAspectCrop`，导入时不缩放、不重新编码，避免低清放大。
- 浅色和深色模式统一使用半透明遮罩、玻璃面板和对应文字色；没有壁纸时回退为纯色。
- 首页改为单张居中卡牌横向分页，不叠卡。正面展示真实应用图标、名称、时长、占比和
  时间故事；翻面展示首次记录、累计时长、记录日数、跨度与个性化换算。
- 卡牌可以直接生成 1080×1920 分享图并调用 Android 系统分享面板。分享图包含真实
  应用图标，默认过滤窗口标题、网址、联系人和包名。
- 统计严格分为本周、本月、今年、总计四个功能块。进入详情后按应用展示真实图标、
  大众化名称、时长、占比和相对进度条。
- 记忆湖接入当月真实聚合数据；“最近被记住”使用日期、应用和时长生成文学化时间线。
- 月度报告合并为一个完整叙事，采用 QML Canvas 原创季节背景，不依赖现成图片；
  可逐页浏览并导出统一分享图。
- 设置页提供权限、立即同步、自动同步、壁纸选择/清除、浅色模式、减少动态效果、
  匿名分享和本地优先说明。

## 数据与隐私

- 自动使用数据仍只由既有 Android UsageStats 导入并写入既有移动端数据表，没有修改
  服务采集契约或数据库 schema。
- 壁纸与分享图由 `MobileUiService` 保存到应用私有目录，不进入使用数据数据库。
- 应用图标优先使用 Android 元数据解析得到的本地文件；解析失败时使用首字回退图标。
- 卡背换算文案在歌曲、诗、茶、电影四种表达中确定性变化，不伪造次数或事件。
