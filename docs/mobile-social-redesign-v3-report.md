# TimeArc 手机端社交化时间卡 v3 设计报告

日期：2026-07-11

## 目标

重新建立 TimeArc 手机端的视觉与内容表达，让首页应用卡、统计、记忆湖、月报和设置形成同一套可迁回 QML 的产品语言，并把卡牌背面从工程数据表升级为用户愿意保存和分享的时间故事。

本阶段交付高保真 HTML/CSS/JS 原型，不修改采集服务、SQLite schema、磁盘契约或生产 QML。

## 设计结论

创意母题为「口袋时间唱片册」。按用户连续三轮评审，最终收束为三个核心模式：壁纸承载卡牌、低饱和双栏时间百科、单一大数字分享封面。

设计只提取参考产品中可复用的模式：

- 网易云音乐：内容先于控件、数据转成个人关系叙事、报告有故事节奏。
- 小红书：移动端内容层级清楚、卡片可扫读、分享入口自然。
- 微信朋友圈：按日期回看、信息克制、时间线有生活记录感。
- Days Matter：一个大结论配少量真实证据，适合生成纪念卡。

没有复制这些产品的品牌红色、VIP/粉丝/等级语义、组件造型或专有视觉资产。默认使用纯色背景；用户可从本机上传壁纸，壁纸会贯穿首页、统计、记忆湖和设置，并可随时恢复纯色。TimeArc 保留湖水青作为唯一全局控制色，应用色只作为内容数据出现。

## 信息架构

保留生产端既有四 Tab，重新明确每页职责：

1. 首页：居中的当前卡牌是唯一内容主角，相邻卡牌左右错位并叠在下层；滑动后下一张进入中心。正面通过可移除的 `memory-glass` class 采用记忆湖式深色透明层，壁纸穿透卡面、应用色只在图标后形成轻微氛围光；下层卡隐藏内部文字以避免透明重影。顶部只保留透明工具条和记录起点、累计记录、记录天数三项事实。
2. 统计：日、周、月、年切换，提供趋势、类别去向、应用排行和可验证洞察。
3. 记忆湖：月报封面、按日期排列的记忆流、历史月报归档。六月、五月、四月、三月均使用原创 CSS/Canvas 几何风景，不依赖现成照片，并各有独立色彩和五段叙事模板。
4. 我的：权限、隐私、主题、分享和数据管理，工程诊断折叠到次级区域。

## 卡牌背面

背面不再显示包名、UsageStats 或 SQLite 说明。结构固定为：

1. 双栏时间百科：「现有记录中的第一次」与「累计相遇」，分别展示时间锚点、前台记录片段数与口径。
2. 关系锚点：例如「从现有记录中的第一次算起，今天是你们时间故事的第 486 天」。
3. 一句话主叙事：例如「深夜里，声音陪你走了很久」。
4. 两条真实证据：累计已记录、有记录的日子或常见时段。
5. 明确口径的换算：必须包含「若按」或「相当于」，并附「不代表实际播放/阅读/完成量」口径。
6. 匿名分享入口：先预览，再保存。

原型只提供一套统一的「时间纪念卡」，不再要求用户在四种近似样式之间判断。它把真实软件图标、巨大的 `N 天`、日期范围、故事标题、两项证据和换算口径合并在同一张 9:16 海报里，并使用同一结构化模型驱动 DOM 预览、复制文案和 1080x1920 Canvas 导出；匿名模式会同时隐藏应用名称、图标与品牌色。

## 数据边界

现有桌面聚合已经能派生最早保留记录、前台记录片段数、最长单段、主要时段、前台与音频拆分、月度占比和趋势，不需要修改采集 schema。

Android 当前 QML dashboard 仍缺 per-app 会话数、最长单次、主要时段和连续天数。HTML 中这些字段是代表性 mock/derived 数据，生产迁移时必须由 `MobileUsageService` 从现有 repository 会话查询中只读聚合，不能把 mock 常量带入 QML。

「播放次数」「读了多少字」「完成多少稿」不是现有采集字段。「第一次使用」也不能由最早保留记录推出。生产文案统一使用「现有记录中的第一次」「累计相遇 N 段」「最长单段记录」；诗意表达只能作为明确口径的估算，不能写成用户真的完成了这些行为。

HTML 原型继续使用仓库内的小红书和哔哩哔哩图标，并从本机已安装程序提取网易云音乐与 VS Code 的真实系统图标。生产 QML 应复用现有 `image://appicon` / `appIconPath` 链路，并在缺失时回退到首字图标。

- Track B preflight 通过。

- Canvas 纪念日分享图生成校验通过：PNG 1080x1920，带 TimeArc 记忆湖背景的测试样本约 2.1 MB；匿名文件名不含应用 ID。

## 已知缺口

- 这是设计与交互原型，尚未迁入 `qml/mobile/`。
- Android 自然月口径、per-app 会话聚合、首次记录日与分享导出仍需生产实现。
- iOS 全局应用采集能力与 Android 不等价，不能直接套用同一数据承诺。
- 真机还需验证 safe area、系统字体、Android 分享 sheet、文件权限、大字号和屏幕阅读器。

## 回滚

本阶段没有修改生产运行路径。回滚只需删除上述新设计上下文、HTML 原型和本报告，并还原 backlog/open-issues/README 的说明，不影响 TimeArc 二进制或用户数据。
