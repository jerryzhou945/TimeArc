## 3. Root cause

- Immediate cause: the linker could not overwrite `build/TimeArc.exe`.
- Underlying cause: a running local `TimeArc.exe` process still held the output file open.
- Why the harness/checklists did not prevent it: the build harness correctly recorded the failure, but it cannot close a developer-run app automatically.

## 4. Fix

- Files changed: none.
- Short description: stopped the running `TimeArc` process and reran the harness build.
- Commit: pending in the site icon commit.

## 5. Prevention

One-off local process lock. When relinking fails with `cannot open output file TimeArc.exe: Permission denied`, close the app or stop the `TimeArc` process before retrying.
