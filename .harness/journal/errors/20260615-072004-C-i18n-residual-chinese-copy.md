## 1. What happened

English language mode still shows Chinese residual copy across home, calendar, stats, settings, and memo overlay; home/memo also show duplicated instructional hints.

## 2. Evidence

```
User screenshots showed English mode still rendering Chinese copy in:
- Memory Lake today conclusion and duplicated carousel hint text.
- Calendar selected-date panel, agenda tabs, and Chinese weekday date labels.
- Stats week/month/year date labels, "上周" delta text, insight text, and weekday labels.
- Settings light-mode/accent/privacy/import-export/memo helper copy and bottom review entry.
- Memo sticky note title/tag/due/todo labels, bottom hint text, and page sidebar count.
```

## 3. Root cause

- Immediate cause: Several visible strings were generated by page-local helper functions,
  custom component labels, and hardcoded model data instead of `I18n.t()` /
  `I18n.sentence()`. The Memory Lake carousel rendered both wheel and hover hints
  at the same time.
- Underlying cause: The first global i18n pass covered common navigation and settings
  labels, but not dynamic date formatting, generated summaries, memo chrome, or
  duplicated hint state.
- Why the harness/checklists did not prevent it: Existing verification catches build
  and Qt runtime issues, but there is no visual or static English-mode CJK residual
  gate for QML surfaces yet.
