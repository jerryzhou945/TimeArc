- Immediate cause: the search-field overlay requested `Cursor.text()` while
  `PlatformCursor.js` does not define a `text()` helper.
- Underlying cause: the page mixed the project cursor abstraction with a native
  Qt cursor that already has a stable enum (`Qt.IBeamCursor`).
- Why the harness/checklists did not prevent it: the existing static UX test
  checked pointer semantics but did not reject undefined cursor-helper calls.

## 4. Fix

- Files changed: `qml/desktop/pages/DesktopStatsPage.qml`,
  `tests/desktop_ux_static_test.py`
- Short description: use `Qt.IBeamCursor` directly and add a regression check
  rejecting `Cursor.text()` from the statistics page.

## 5. Prevention
