Goal: Check whether the Qt GUI read paths and native service write paths resolve to the same disk locations on Windows, macOS, and Linux.

What happened: Inspected the data-contract rule and traced the shared path helpers, UI database/config/live/fallback readers, and service storage/config callers.

Outcome: Investigation only; no application code changes. Windows paths align for JSON/live/config and align for SQLite by convention/config pointer. macOS/Linux are not proven aligned: active macOS/Linux services do not currently write usage records, and the Qt JSON/config helper falls back to ~/TimeArc/usage while shared Unix service paths use ~/.timearc/usage.
