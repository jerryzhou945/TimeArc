## Two-sided design

**Service side.** Foreground collectors and the service-owned SQLite contract do
not change. Android UsageStats continues to be imported through the existing
mobile repository; this feature neither adds a sampler nor changes service
tables, filenames or write ownership.

**UI side.** `MobileUsageService` adds truthful calendar-range and per-app
presentation facts. A focused `MobileUiService` owns wallpaper import into app
storage and share-file handoff. QML consumes those two QObject APIs to render the
four persistent tabs, real app icons, single-card carousel, period rankings,
Memory Lake stories and privacy-safe share previews.
