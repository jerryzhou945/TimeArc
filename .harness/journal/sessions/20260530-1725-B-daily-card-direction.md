# Session 20260530-1725-B-daily-card-direction

## Goal

Capture the product and technical direction discussed for TimeArc as a
local-first life timeline tool, centered on Daily Cards and explicit privacy
boundaries.

## Service side

No service behavior changes in this session. The proposed future direction
keeps the service as a lightweight collector of app usage, window title, and
audio activity metadata, with no screenshots, raw audio, or chat content.

## UI side

No UI behavior changes in this session. The proposed future direction points
Memory Lake or a future Daily Card UI at locally generated summaries derived
from usage, project, timer, calendar, and optional context data.

## Rules

No rule files need updating because this is a new product/design document only.
No schema or `data_bridge.h` changes were made.

## Outcome

Added `docs/life-timeline-product-direction.md` documenting positioning, data
boundaries, Daily Card MVP, technical pipeline, AI summary strategy, and
non-goals.
