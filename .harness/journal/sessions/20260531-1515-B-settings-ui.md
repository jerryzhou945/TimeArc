# Goal

Polish the TimeArc settings/profile page by borrowing the simpler overall settings-page feel from Ceceliaee/time-tracking without copying code.

# Design

Service side: no service behavior changes; the background sampler continues emitting the same disk journal and live snapshot contract.

UI side: update the existing QML settings/profile page presentation only, preserving current theme plumbing and Chinese-first text while tightening layout, spacing, and scaling behavior.

# Scope

Expected touches: QML settings/profile page files and possibly nearby QML-only components.

Rules: `rules/04-ui-conventions.md`.

Avoid: frozen files, service code, data schema, build system, README unless a visible feature description changes.

# Outcome

Reworked `DesktopProfilePage.qml` into a quieter settings-style page with top-to-bottom functional sections, click-to-select light/dark theme choices, a persisted Chinese/English settings-page language preference, database path display, and a fixed 1040x650 design frame that only scales down uniformly instead of stretching.

Follow-up polish deepened the outer border and light-mode contrast, and changed section panels to size from their content so rows are not clipped by panel borders.

Final ratio fix moved the aspect lock to `DesktopAppShell.qml`: the main content panel now keeps a 16:10 rectangle inside the available slot, while the settings page scales uniformly within it.

Outer ratio lock added in `qml/main.qml` so the application window itself keeps 16:10 during width or height changes; `DesktopAppShell.qml` also renders inside a fixed 1440x900 stage that scales uniformly.

Internal layout was restored to normal fill behavior: the app shell and settings page no longer use fixed inner stages, leaving only the outer `ApplicationWindow` aspect lock.

Removed the Memory Lake 8-frame timer animation and kept a single asynchronous static hot spring image to reduce continuous QML repaint work.

Reverted the cached `StackLayout` page switching experiment because it made runtime switching feel worse; desktop navigation is back to the original single `Loader.source` swap model.
