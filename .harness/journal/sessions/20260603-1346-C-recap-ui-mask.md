## Root cause
`clip: true` on a `Rectangle { radius }` clips to the rectangular bounding
box, not the rounded corners (same class as the card cover leak fixed in
MemoryCard.qml). Square child corners poke past the rounded border.

## Fix plan (one commit per problem; PR base dev after problem 1)
1. monthMap fill: per-corner `bottomLeftRadius/bottomRightRadius` = cell radius
   (Qt 6.7+; top stays flat — it is a fill level indicator).
2–5. New reusable `RoundedFrame.qml` (composite children into a multisampled
   layer, single rounded `MultiEffect` mask + shared rim — same pattern as
   MemoryCard). Replace the four image containers. Register in qml/CMakeLists.txt.
6. Round the RecapOverlay backdrop to align with the content panel corner.
